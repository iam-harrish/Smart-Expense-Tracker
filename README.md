# 💰 Smart Expense Tracker (Java Console Application)

A simple and efficient console-based Expense Tracker built using Java.  
This application helps users record daily expenses, view spending history, and analyze expenses by category.

---

## 🚀 Features

- Add new expenses (date, category, amount)
- View all recorded expenses
- Calculate total spending
- Category-wise expense summary
- Persistent data storage using file handling

---

## 🛠️ Tech Stack

- Java (Core Java)
- File Handling (BufferedReader, FileWriter)
- Collections (HashMap)

## ▶️ How to Run

1. Clone the repository:
   git clone https://github.com/iam-harrish/Smart-Expense-Tracker.git
2. Navigate to project folder:
   cd Smart-Expense-Tracker
3. Compile:
   javac src/Main.java
4. Run:
   java -cp src Main
